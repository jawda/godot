Before you draw

  1. Block the silhouette at 1× — if it does not read at 192 px it will not read in game.
  2. Draw every KEY frame across all rows before any in-between, so the character stays on-model.
  3. Keep the palette locked. Add shades only for the weapon glow and the death dissolve.
  4. Export one PNG, power-of-two padded, no trim, alpha preserved.
